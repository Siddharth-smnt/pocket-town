# Roadmap

## Before first release

1. Complete physical-device testing and fix observed issues.
2. Test progression with players; adjust prices/piece pool from actual sessions.
3. Finalize app identity, signing, support/privacy pages, store assets and Play testing.
4. Review audience/consent before any production monetization.

## Potential later features

- Seeded daily puzzles, additional towns and optional themes.
- Cosmetics with proper Play Billing acknowledgement, restoration and entitlements.
- Export/import or cloud saves with explicit account/privacy choices.
- Shared towns, friends and leaderboards with a backend and synchronization design.
- Localization and further accessibility/low-end-device improvements.

These are future work, not implemented services. No retention, revenue or Play approval is guaranteed. The current game is independently playable.
